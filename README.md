# FARO

Personal treasury for córdobas and dollars. Each month is its own ledger. Amounts stay in the currency you entered; the desk converts the view at the rate you keep (BCN backup 36.6243 for 12 Oct 2026, or a manual rate).

Sign in with email, Google, or X. The same account stores one ledger online and a copy on each device. If the network is down, edits stay on the device and sync when it returns. If two devices disagree, the newer revision is kept and the other copy can be restored from Settings.

Backup file: `FARO_Backup_YYYY-MM-DD.json`.
