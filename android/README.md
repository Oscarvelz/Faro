# Faro for Android

A thin WebView app around https://oscarvelz.github.io/Faro/ (package `com.oscarvelz.faro`, min Android 11).
Web releases arrive on their own (the page is loaded live; the service worker keeps it working offline).

- Bridge: `window.FaroNative` (see `src/spa/native.ts`, feature-detected; the browser/PWA never see it):
  Back (`FaroBack` → `atRoot`), bar colours, downloads into Downloads/Faro, BiometricPrompt for the fingerprint lock,
  pictures shared from other apps (scan preview), update offer from GitHub releases `android-N` (asset `Faro.apk`).
- Notifications (2026-11-07, `FaroNotify.kt`): due payments (overdue or <= 2 days away, once per due), spending pace
  (projected to pass the month's income, at most once a week) and the month-close report, all computed locally from the
  same widget snapshot (amounts hidden when the snapshot hides them) and posted on the `faro-avisos` channel. Checked on
  each new snapshot and at the widgets' midnight tick; taps take the widgets' `faro.WIDGET` route. Android 13+ asks
  POST_NOTIFICATIONS once (MainActivity); everything is gated on notifications being enabled.
- Home-screen widgets (1.3.121, `FaroWidgets.kt`): "Faro · Mes" (phone, 4×1 to 4×4), "Faro · Panel" (tablet, 6×4 and up)
  and "Faro · Vencimientos" (phone, the dues on their own; rows follow the widget's height). Every widget has placement
  options (`WidgetConfigActivity`, `WidgetCfg` in `FaroWidgets.kt`): amounts follow the app, always show or always
  hide — per widget instance, applied by copying the snapshot with the effective hide before rendering.
  The page sends a privacy-safe snapshot with `FaroNative.setWidgetData(json)` (`src/lib/faro/widget.ts`: amounts in minor
  units, no card digits, no people, no notes); it lives only in the app's private SharedPreferences `faro-widget`. No network.
  Taps open the app with action `faro.WIDGET` + `go`; the page takes it with `FaroNative.takeOpen()` after the lock.
  Layouts are plain RemoteViews (day/night via `values-night`); the tablet layouts are generated by `app/gen_panel.py` (run it in
  `app/src/main/res/layout`). Shots: `.github/workflows/widget-shots.yml` (Robolectric, branch `widget-dev`).
- Build: `.github/workflows/android.yml` on the `source` branch (only when `android/` changes). versionCode = run number.
- Signing: the key is private and never committed. With repo secrets `FARO_KS_B64` + `FARO_KS_PASS` CI signs and
  publishes; without them CI uploads `faro-unsigned-N`, the APK is signed privately (apksigner, alias `faro`) and pushed
  to the orphan branch `android-signed` (`Faro.apk`, `VERSION`=N, `NOTES.md`), whose workflow publishes release
  `android-N`. All updates must use the same key (certificate SHA-256 8f:e1:ad:7c:…:63:4b:98).
- Download: https://github.com/Oscarvelz/Faro/releases/latest/download/Faro.apk
- Storage is separate from Chrome: sign in once (sync) or import a backup.
